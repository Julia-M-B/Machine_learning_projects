## Current Projects

### [Skip-Gram Model with Negative Sampling](./skip-gram-model/)

A PyTorch implementation of a Skip-Gram model with negative sampling for Polish language word embeddings. This project provides a complete pipeline for preprocessing Polish text data, building vocabulary, and training word embeddings.

**Features:**
- Polish language text preprocessing with optional lemmatization
- Vocabulary creation and management
- SQLite database integration for large-scale data handling
- Skip-gram model training with negative sampling
- Model evaluation with word similarity search and word arithmetic

See the [project README](./skip-gram-model/README.md) for detailed documentation, usage instructions, and configuration options.
